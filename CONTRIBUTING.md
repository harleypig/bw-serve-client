# Contributing

The contributing guide is [`docs/developer/contributing.md`][guide]: issues,
branches, pull requests and releases. Setting up a checkout is
[Development Setup][dev].

- **A bug or a feature request:** open an issue with one of the
  [issue forms][new-issue].
- **A security vulnerability:** report it privately through
  [private vulnerability reporting][advisory], never in a public issue.
- **Conduct:** everyone taking part follows the [code of conduct][coc].
